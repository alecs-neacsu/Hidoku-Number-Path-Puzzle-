# Hidoku: Number Path Puzzle

Play Hidoku in your browser: **https://alecs-neacsu.github.io/Hidoku-Number-Path-Puzzle-/**

Fill the grid with the numbers 1 to N so that each number touches the next one — horizontally,
vertically or diagonally.

- Six board sizes (6×6 up to 10×12) and four levels
- New puzzles generated in the browser, always with a unique solution
- 720 ready-made puzzles (the same collection as the Android app)
- Progress saved in your browser, connection bars, English and Romanian, light and dark theme
- Printable puzzle sheets (1, 2 or 4 per page, A4 or Letter) with optional answer pages
- Works offline once loaded. Free, no ads, no tracking.

Static site, no build step: `index.html`, `app.js` (UI), `core.js` (solver/generator), `worker.js`,
`puzzles.json` (collection), `sw.js` (offline cache).
